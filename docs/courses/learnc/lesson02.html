Your First C Program

Write "Hello, World!" and understand every single character — what it does, why it's there, and what happens when you press Run.

The Hello World Tradition

Every programmer's first program is Hello, World! — it is a tradition that started with C itself, in the original 1978 C book by Kernighan & Ritchie. When you write it, you join millions of programmers who started exactly the same way.

Example 1 — The Classic Hello World
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
Hello, World!
This is the most famous program ever written. Let's understand every single line of it.

Understanding Every Line

Line-by-Line Breakdown — Every character explained
#include <stdio.h>
#include means "borrow code from a file". stdio.h is a header file that gives us printf and scanf. Without this, printf would not exist. Think of it like importing tools from a toolbox.
(empty line)
Empty lines are ignored by the compiler. We use them to make code easier to read — like a gap between paragraphs in a book.
int main() {
main() is where every C program starts running. The word int means it will give back a number when done. The { curly brace opens a block of code — like opening a box.
printf("Hello, World!\n");
printf = "print formatted". It displays text on the screen. The text inside " " is called a string. \n means new line (like pressing Enter). The ; semicolon ends every statement in C.
return 0;
return 0 tells the operating system "my program finished successfully". 0 = success, any other number = error. This is mandatory in main().
}
The closing } curly brace closes the main() function — like closing the box we opened earlier. Every { must have a matching }.

Comments in C

Comments are notes you write for yourself (and other programmers) that the compiler completely ignores. Good code always has comments explaining why things are done.

Example 2 — Two Types of Comments
#include <stdio.h>

// This is a single-line comment
// Use // for short notes on one line

/* This is a multi-line comment.
   Use this for longer explanations
   that span multiple lines. */

int main() {
    // Print a welcome message
    printf("Welcome to C Programming!\n");

    printf("Let's learn together!\n"); // comment can go here too

    return 0; /* exit with success */
}
Welcome to C Programming! Let's learn together!
Comments never appear in the output. Write comments freely — they make your code 10x easier to understand later.

The printf Function — Printing Text

printf is your main tool for displaying output. It can print text, numbers, and use special escape sequences.

Example 3 — printf Escape Sequences
#include <stdio.h>

int main() {
    printf("Line 1\n");          // \n = new line
    printf("Line 2\n");
    printf("Col1\tCol2\tCol3\n"); // \t = tab space
    printf("Say \"Hello!\"\n");    // \" = print a quote
    printf("Back\\slash\n");    // \\ = print a backslash

    return 0;
}
Line 1 Line 2 Col1 Col2 Col3 Say "Hello!" Back\slash
\n, \t, \" and \\ are called escape sequences. They start with a backslash and represent special characters you can't type directly inside a string.
Escape Sequence Reference
Escape Meaning Example Output
\nNew lineMoves cursor to next line
\tTabAdds a tab space (like pressing Tab)
\"Double quotePrints " character
\\BackslashPrints \ character
\0Null characterUsed to end strings in C

How C Compiles Your Code

When you click Run in our editor, here is what happens behind the scenes:

Compilation Steps
Step 1 — Preprocessing: The compiler reads #include and pastes the stdio.h file content in
Step 2 — Compilation: Converts your C code to assembly language
Step 3 — Assembling: Converts assembly to binary machine code (0s and 1s)
Step 4 — Linking: Connects your code with library functions like printf
Step 5 — Execution: The CPU runs the final binary → you see the output!
In our editor this all happens in under 2 seconds. On your computer you'd type: gcc main.c -o output then ./output
⚠ Most Common Beginner Mistakes

1. Forgetting the semicolon — Every statement must end with ;
2. Wrong case — C is case-sensitive. printf ≠ Printf ≠ PRINTF
3. Missing #include — Without stdio.h, printf does not exist
4. Mismatched braces — Every { needs a closing }

🎯 Key Takeaway

Every C program needs: #include <stdio.h> for I/O, int main() { } as the starting point, and return 0; to signal success. Master these 3 parts and you can build anything. The rest of the course adds more tools to your toolbox.

✅ What You Learned

#include borrows tools from header files · main() is where C programs start · printf prints text to screen · \n adds a new line · ; ends every statement · // and /* */ are used for comments · return 0 tells the OS the program succeeded

What does the \n inside printf do?

Explanation \n is the newline escape sequence. It tells printf to move the cursor to the next line, just like pressing Enter on a keyboard. Without \n, all your printf output would appear on the same line! \t is for tab, the program ends with return 0, and \n never prints an actual "n".
